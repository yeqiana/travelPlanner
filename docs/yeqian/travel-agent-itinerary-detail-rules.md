# Travel Agent 详细行程生成规则

## 结论

最终行程仍保持 `DailyPlan.morning / afternoon / evening` 旧结构，但每段文本必须尽量写成可执行日程，避免只输出空泛模板。

## 输出要求

- 每天至少覆盖上午、下午、晚上 3 个活动段。
- 每个活动段尽量包含时间、地点、活动、交通建议、预计耗时或二次确认提示。
- 没有真实数据时，可以使用“候选地点 + 需二次确认”，不能写成确定性实时票价、余票或开放状态。
- 避免大量出现“核心景点游览”“自由活动”“轻松收尾”等空泛表达。

## 当前兜底城市

当前轻量规则先覆盖：

- 杭州：西湖苏堤、灵隐寺、河坊街。
- 上海：外滩、豫园、陆家嘴。
- 西安：陕西历史博物馆、大雁塔、回民街。
- 宝鸡：法门寺文化景区、太白山游客中心、陈仓老街。

未覆盖城市使用“城市地标候选点、博物馆或公园候选点、特色街区候选点”并标注二次确认。
