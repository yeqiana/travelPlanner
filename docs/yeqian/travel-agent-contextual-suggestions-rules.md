# Travel Agent 上下文快捷提示规则

## 结论

快捷提示由后端根据当前响应状态生成，前端优先展示 `contextualSuggestions`；字段为空时，前端保留固定提示兜底，避免旧响应出现空白。

## 生成规则

- 追问场景：围绕缺失字段生成提示，如“补充出发城市”“补充出发日期”“补充出行天数”。
- 预算缺失：提示“补充预算范围”。
- 已有完整计划：提示“调整第2天节奏”“换一些当地餐厅”“细化每天上午下午晚上安排”。
- 多城市计划：提示“减少跨城交通”。
- 细化意图：优先提示“继续细化交通和餐饮”。

## 前端展示

- `contextualSuggestions` 有值时展示后端返回内容。
- 没有返回时展示固定兜底：增加一天行程、换一些餐厅、太累了减少景点。
- 点击快捷提示后继续作为普通用户消息发送，复用现有会话和接口。
