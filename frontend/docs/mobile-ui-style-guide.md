# AgentTravel 移动端 UI 风格指南

本文档记录当前 AI Studio 生成的 AgentTravel 移动端页面风格，用于后续 TravelPlanner 前端页面生成、重构和 UI 走查。

## 设计定位

AgentTravel 是移动端优先的 AI 旅行规划 WebApp。界面应保持轻量、清晰、可对话，重点突出“告诉 AI 需求、生成行程、继续追问、查看时间线”的核心体验。

当前风格适合作为原型基线，但后续扩展时需要沉淀样式 token 和复用组件，避免继续堆叠大段 Tailwind class。

## 品牌气质

- 清爽、可信、移动优先。
- 偏年轻化，但不做过度装饰。
- AI 助手感明显，以聊天、推荐 chip、行程卡片和时间线作为核心表达。
- 旅行内容应突出地点、时间、路线、预算和提示，不使用营销落地页式大 hero。

## 色彩规范

当前代码中的主视觉为蓝白体系：

- 主色：蓝色，建议 token 为 `--color-brand-primary`，参考 Tailwind `blue-500`。
- 主色深态：参考 `blue-600` / `blue-700`，用于主要按钮 hover、强调文字。
- 主色浅态：参考 `blue-50` / `blue-100`，用于 chip、轻提示、选中背景。
- 文本主色：接近 `gray-900`，用于标题和主要正文。
- 文本次色：接近 `gray-500` / `gray-600`，用于说明、摘要、辅助信息。
- 页面背景：白色为主，弱区域可使用 `gray-50`。
- 输入背景：当前多处使用 `#f4f4f5`，建议沉淀为输入底色 token。
- 辅助强调：
  - 黄色用于“生成一图流”等强行动作。
  - 橙色用于旅行 tips。
  - 玫瑰色用于酒店估价。
  - 琥珀色用于餐饮估价。

禁止把页面做成单一蓝色堆叠。蓝色用于行动和选中，内容卡片仍以白色、灰色和局部辅助色保持层次。

## 字体层级

移动端字体层级应克制，避免桌面式大标题：

- 页面标题：20px 到 24px，粗体。
- 区块标题：17px 到 20px，粗体或特粗。
- 正文：14px 到 16px，行高舒适。
- 表单标签：14px 到 15px，半粗或粗体。
- 辅助文字：11px 到 13px。
- 按钮文字：14px 到 18px，根据按钮尺寸决定。

原则：

- 卡片内标题不要使用 hero 级字号。
- 长文本必须允许换行，不允许溢出容器。
- 不使用负字距，不使用随视口宽度变化的字体大小。

## 圆角与阴影

当前页面大量使用圆润 UI：

- 小按钮、标签：8px 到 12px。
- 输入框、普通卡片：16px 到 20px。
- 大卡片、弹窗：24px。
- 头像、图标按钮、chip：可使用全圆。

阴影应轻量：

- 普通卡片使用浅灰阴影或边框。
- 主按钮可使用轻微彩色阴影。
- 不要用大面积厚重阴影制造悬浮感。
- 弹窗和侧边抽屉可以使用较明显阴影，但背景层级要清楚。

## 间距

移动端页面以单列扫描为主：

- 页面左右边距：16px 到 24px。
- 卡片内边距：16px 到 24px。
- 表单项间距：20px 到 24px。
- 紧凑信息行间距：8px 到 12px。
- 底部输入区域必须预留安全区，避免遮挡移动端系统手势区。

## 组件模式

当前可沉淀的组件模式：

- 顶部导航栏：左侧菜单，中央或左侧品牌，右侧搜索或工具按钮。
- 侧边抽屉：历史行程、新建行程、用户偏好入口。
- 首页表单：目的地、天数 stepper、偏好 chip、同行人 chip、补充要求。
- 聊天气泡：用户右侧蓝色气泡，AI 左侧头像和内容流。
- 底部输入框：固定底部，支持推荐追问 chip 和发送按钮。
- 行程卡片：标题、摘要、按天分组、活动时间线、估价标签、交通提示。
- 弹窗：
  - 全屏搜索适合移动端搜索历史记录。
  - 居中弹窗适合偏好设置。
  - 底部或全屏弹窗适合分享和海报生成。

## 动效规范

当前使用 `motion` 做轻量动效：

- 页面进入可使用轻微透明度和位移。
- 抽屉使用横向滑入。
- 弹窗使用透明度、轻微缩放或位移。
- 加载态可以使用三点跳动。

动效原则：

- 动效服务于状态变化，不做纯装饰。
- 按钮 active 可使用轻微 scale。
- 避免影响列表滚动和输入响应。

## 后续 token 建议

后续目录重构时建议新增 `frontend/src/styles/tokens.css`，至少沉淀：

- 品牌色、文本色、背景色、边框色。
- 移动端字号层级。
- 圆角层级。
- 阴影层级。
- 常用 spacing。

在 token 建立前，新增页面应优先复用现有视觉规律，避免随意引入新的颜色体系。
